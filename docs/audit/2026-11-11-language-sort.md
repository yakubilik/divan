# Sorting the Turkish in the tree into data and prose (11 Nov 2026)

The audit job (`python3 scripts/audit.py`) had 694 findings in tracked files: 681 Turkish letters or
words, 12 home paths or hostnames, one key header. Each was sorted here: data the code or a test
cannot do without is excused, by path or by a marked block, with the reason beside it; prose was
translated; the personal strings were replaced. No rule was loosened. The live list of everything
excused, with the reasons, is always `python3 scripts/audit.py --exemptions`; this file is the
record of what this sort decided.

## The marked block

A file that is partly data marks the part:

```
// audit: language-data — <why these lines are data, five words or more>
...
// audit: end-language-data
```

The lines between the markers are excused from the language rules only; a secret, home path or
hostname inside one is still a finding. A block with no reason, one never closed, one opened
inside another and a close with nothing open fail the scan (`scripts/test_audit.py` checks each).
JSON has no comments, so a JSON file of data is listed by path in `ALLOW`.
