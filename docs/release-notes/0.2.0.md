# v0.2.0

The first tagged release: your own computer's coding agent, reached from your
phone over your own network, with the daemon, the iOS app and the desktop
panel all cut from one commit. It is also the first release with a voice call
to the computer, its screen in your hand, and a panel that draws every chat as
a window on a wall.

## What is in it

- **The shape of the thing.** A Python daemon next to Claude Code and Codex, an
  iOS app, and a desktop panel served by the daemon itself. WebSocket over your
  tailnet, no relay, no account, no cloud.
- **You approve, it runs.** Every shell command stops in `ask` mode, and a
  dangerous one stops even in `bypass` — answerable from the lock screen.
- **A voice call to the computer.** A concierge that can see every chat on that
  machine and say what each one is doing; the phone rings through CallKit
  whether or not the app is open.
- **The computer's screen, in your hand.** A few frames a second and a pointer,
  on macOS and Windows, every monitor listed. Watching starts on Connect;
  clicking stays off until `remote_control` is turned on in `config.toml`.
- **Terminal mode in the panel.** Every chat as a terminal window on a wall you
  arrange yourself, with approvals answered from the tile.
- **Agents.** The agents defined on a computer are listed on both clients, and
  a card can start a chat with one.
- **Both of a chat's ids**, in full and copyable, in the panel's inspector and
  the phone's chat settings — one for a bug report, one for `claude --resume`.
- **A turn survives the daemon.** A restart picks up the turns that were in
  flight and the messages nobody answered, in the order they were asked.
- **A message reaches a running turn** at its next step rather than waiting
  behind it.
- **The app, drawn again**, light and dark, one to one with the design.
- **Windows, macOS and Linux** each install with one script, and the daemon
  registers itself to start at login.

Notable fixes: a tapped notification opens the chat it is about instead of an
empty one (and stops deleting it), the panel's copy buttons work on the
address the panel is actually opened at, the remote screen no longer freezes
two frames in, and a zoomed tap lands where the finger did.

The full list is in [CHANGELOG.md](../../CHANGELOG.md).

## Upgrading

**The daemon updates itself.** `auto_update` is on by default: every 15 minutes
it fast-forwards its checkout to `origin/main`, rebuilds the panel if `web/`
moved, and asks its supervisor to restart it. A computer you are not sitting in
front of picks this up on its own, as long as its checkout is clean.

By hand, or with `auto_update = false`:

```bash
cd remote-ai-chat && git pull --ff-only
cd daemon && ./install.sh          # or: install.ps1 on Windows
```

The wheel and sdist attached to this release install the daemon without a git
checkout — but then nothing updates itself, and `update.status` has no repo to
report on.

**The app** is not part of the tag. Install it from TestFlight or the App
Store; a build from source is `cd app && npx expo run:ios --device`. An older
app talks to a 0.2.0 daemon, it just does not draw what it has never heard of.

Nothing in this release changes `config.toml`, the database or the protocol in
a way that needs a hand. Devices stay paired.
